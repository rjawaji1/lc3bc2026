# Try the replay viewer

Open `../viewer/index.html` in your browser and select **`showcase.replay.jsonl`**.
It was generated by compiling `team1.asm` and `team2.asm` with elk and running the
CLI against `showcase.map`.

The match has 12 snapshots (initial state plus 11 ticks):

- Tick 1: both mice collect cheese.
- Tick 4: both deposit it at their own altars, making the score 1–1.
- Tick 7: both collect another cheese.
- Tick 10: they meet in the center.
- Tick 11: team 1 attacks; team 2 waits, dies, and drops its carried cheese.
- Team 1 wins by elimination despite the tied score.

## Compile and run again

From the repository root:

```sh
elk examples/team1.asm --assemble --output examples/team1.obj \
    --trap-aliases 'move=x30,attack=x31,halt=x25' --strict
elk examples/team2.asm --assemble --output examples/team2.obj \
    --trap-aliases 'move=x30,attack=x31,halt=x25' --strict
odin run . -- run examples/showcase.map examples/team1.obj examples/team2.obj --replay examples/next-match.replay.jsonl
```

Choose a new replay path for each run; existing files are not overwritten.
The examples compile with `--strict`; no warning suppression is needed.
`--trap-aliases` tells elk that `move` is the game's `x30` trap, `attack` is its
`x31` trap, and `halt` is `x25`. Include this option when assembling or checking
the examples. These aliases emit ordinary LC-3 trap instructions.

Use `--assemble`, not elk's default assemble-and-emulate mode: the game's custom
traps must run inside this simulator. All assembly comments start with `;`, and
instructions and data use four-space indentation, with labels at column one.

These are scripted showcase bots, not intelligent agents. Their action tables
control their routes, and a counter in VM memory advances once per game tick.
Game resets clear registers but preserve this counter. To make the final fight
a mutual kill, change team 2's final `.FILL #5` (wait) to `.FILL #4` (attack),
reassemble, and record to a new replay file.

The action table values 4 (attack) and 5 (wait) belong to these example bots, not
to the movement trap. Values 0–3 are passed to `move` in `r0`: north, west, south,
and east respectively. Change the table entries to experiment with the routes.
